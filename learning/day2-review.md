## 1. SFT 与梯度累积

- labels 错开一位定义下一 token 的目标；因果注意力阻止当前位置读取未来 token；response_mask 控制哪些预测位置计入损失。
- 预测第一个回答 token 时，它不在该位置可见的上下文中，不是因为 response_mask 把它遮住了。
- teacher forcing：即使上一位置最倾向预测错误 token，下一个位置仍使用示范前缀。
- prompt 的预测损失可以被排除，但 prompt 作为回答上下文仍参与计算，不等于冻结 prompt 的嵌入或其计算过程。
- backward 累积梯度，不更新参数；step 才更新参数。累积期间保持同一份参数；累积结束后裁剪梯度、step，下一有效批次前清空梯度。

整除且不补样本、不丢数据时：

    更新次数 = 样本数 / 有效批次 × epoch 数
    backward 次数 = 更新次数 × 有效批次 / 微批次

已答对案例：96 条、3 epoch、有效批次 24、微批次 6 → 12 次 step、48 次 backward。

## 2. EI：生成、筛选、SFT

    当前策略 → 同题多回答 → 评分 → 保留正确回答
         → 内层 SFT → 同步新权重 → 下一轮重新生成

- 筛选不更新参数；内层 SFT 才更新。
- 内层多个 epoch 仍属于一次 EI 外层轮次。
- 训练 policy 与 vLLM 各有权重，下一轮生成前须同步。
- 回答成功率 = 正确回答数 / 总回答数。
- 题目覆盖率 = 至少有一条正确回答的题目数 / 题目总数。
- 容易题可能贡献更多正确样本；整轮没有正确回答时需处理空数据，不能直接训练。

案例：32 题 × 4 回答 = 128 条；48 条正确、来自 20 题 → 成功率 37.5%，覆盖率 62.5%。48 条训练 2 epoch、有效批次 24 → 4 次 step；微批次 6 → 16 次 backward。

## 3. GRPO：奖励、优势与损失

奖励 r 描述评分；优势 A 比较同题回答的相对好坏：

    不除标准差：A_i = r_i - mean(r_group)
    除标准差：  A_i = (r_i - mean(r_group)) / (std(r_group) + eps)

- 正优势鼓励回答，负优势抑制回答；这是各项损失提供的方向，共享参数下不保证每个 token 的实际概率都按单项方向变化。
- 奖励 [1,0,1,0]，只减均值后为 [0.5,-0.5,0.5,-0.5]。
- 全对或全错时，组内优势全零，这项优势策略梯度没有信号。EI 仍可对全对组做 SFT。
- 减均值与除标准差是不同选择。关闭标准差归一化不等于关闭 baseline。
- 除标准差改变组间缩放。小标准差组被放大，但完全同奖励的零优势不会因此变成非零。课堂数字使用总体标准差示意；实现必须核对作业指定的标准差约定。

项目四类逐 token 损失：

| loss_type | 公式 |
|---|---|
| no_baseline | -r × log p_current |
| reinforce_with_baseline | -A × log p_current |
| grpo_no_clip | -ratio × A |
| grpo_clip | -min(ratio × A, clamp(ratio, 1-eps, 1+eps) × A) |

前两类用于本作业 on-policy 对比；后两类用于复用数据时的比率目标与 clip 消融。去 baseline 和去 clip 不是同一个实验。

## 4. 旧策略、概率比与 clip

    ratio_t = exp(current_log_prob_t - old_log_prob_t)

- old_log_probs 在采样后、第一次参数更新前保存，在本批数据全部内层更新中固定。
- 不能每次 epoch 都用 current_log_probs.detach() 覆盖旧概率，否则 ratio 始终为 1，clip 看不到相对采样策略的累计偏离。
- ratio 数值为 1 不代表梯度为 0；分子仍可求导。组内平均 loss 数值为 0 也不等于梯度为 0。
- A>0 且 ratio>1+eps：截断继续增加概率的收益。
- A<0 且 ratio<1-eps：截断继续降低概率的收益。
- clip 使目标在特定方向变平，不是概率或参数变化的硬约束，也不保证训练稳定。
- token 概率比不修正全部前缀分布差异，不能视为完全等价于当前策略重新采样。
- GRPO clip 作用于损失目标；梯度裁剪作用于累积后的参数梯度，二者不同。

## 5. 长度聚合与梯度缩放

| 模式 | 聚合方法 | 微批次等大时，再除累积次数？ |
|---|---|---|
| mask_mean | 每条回答按自己的有效长度平均，再按样本平均 | 是 |
| mask_normalize | 每条回答除固定 C，再按样本平均 | 是 |
| mask_dapo | 微批次 token 损失求和，除整个有效批次的有效 token 数 | 否 |

逐回答平均让每条回答内部权重之和为 1；全局 token 平均让每个有效 token 使用相同系数。二者是不同目标。固定 C 不等于直接奖励长回答。

案例：A 有 2 token、损失和 4；B 有 8 token、损失和 8。

    回答等权平均 = (4/2 + 8/8) / 2 = 1.5
    全局 token 平均 = (4+8) / (2+8) = 1.2

全局 token 平均分微批次计算时，两部分分别为 4/10 与 8/10，分别 backward 即可。若还除累积次数 8，梯度会缩小为目标的 1/8。

外层传入 acc_steps_to_pass=1 是关闭内层额外缩放，不代表外层只循环一个微批次。

## 6. 源码顺序与数据对应

    同步权重 → 同题多回答 → 展平且保持同题相邻
      → 按原组算优势 → 长度过滤/补样本 → 分词
      → 保存旧概率 → 成套打乱索引 → 内层训练

- 生成组按题目定义；训练批次可混合题目。先算好优势后可以打乱，前提是回答、labels、mask、优势、旧概率同时用同一组索引。
- 当前代码补样本是重复抽取已有回答，不是新生成；复制已有优势，不按补齐后的训练批次重新算优势。
- 过滤后保留原组优势，幸存样本优势均值不必为零；若重新计算，就是更换比较基准。
- 不足一个有效批次时代码补齐；超过一个批次但无法整除时，当前整除循环会遗漏本 epoch 的尾部样本。
- 长度检查对 p+r 一起分词，训练分别分词再拼接，两者长度可能不同，需统一口径。
- 外层 step 是采样轮次，不一定是 optimizer.step 次数。
- 32 题 × 8 回答、有效批次 64、微批次 8、2 epoch → 8 次参数更新、64 次 backward，前提是无过滤或补样本改变数量。

## 7. 梯度流与运行模式

| 量或操作 | 要点 |
|---|---|
| current_log_probs | 保留通向模型参数的计算图 |
| old_log_probs | 固定，不求梯度 |
| rewards / advantages / mask | 本次更新中作为固定权重或选择条件 |
| eval() | 改变 dropout 等层的行为，不关闭自动求导 |
| no_grad() | 不记录这段计算的计算图 |
| detach() | 断开张量与原计算图的连接，数值不变 |

no_grad 中算出的当前概率，离开作用域不会恢复模型计算图；事后 requires_grad=True 也不能接回模型，须重新前向计算。

## 8. 训练前检查与实验分析

- 首次更新前，在相同权重、输入、精度和随机层条件下，ratio 应接近 1。旧概率用 eval、当前概率用 train 时须注意 dropout 差异。
- backward 后、step 前参数不变；已知非零梯度且学习率非零时，step 后应能观察到参数变化。
- 随机性受控、目标和分母一致时，整批计算与微批次累积的梯度应接近。
- 奖励、格式通过率、回答长度、截断率、熵和具体样例要联合观察。奖励上升可能主要来自格式改善；熵下降不自动代表能力提高。
- 按更新次数改善慢、按运行时间改善快并不矛盾，可能来自减少生成开销；不同有效批次的一次更新也不等量。
- 熵下降、回答相似、奖励停滞时，先检查样例和评分，再通过减少复用 epoch 检验数据过度复用的猜测。
- 当前 clip_fraction 与 ratio 的统计未排除 prompt/padding，不能直接当作有效回答 token 指标；属于读码发现，尚未修改或验证。
